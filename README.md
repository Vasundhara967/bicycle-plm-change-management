# Bicycle PLM – BOM & Engineering Change Management

## Project Overview

This is a mini PLM functional project demonstrating BOM management, engineering change management, revision control, approval workflows, and product lifecycle management.

The project uses Microsoft Excel to simulate common Siemens Teamcenter PLM processes.

## Business Scenario

A bicycle manufacturing company wants to replace its aluminum bicycle frame with a carbon fiber frame to reduce weight.

**Product Details:**
- Product ID: B100
- Product Name: Bicycle Assembly
- Affected Part: P101 – Bicycle Frame
- Old Revision: A – Aluminum
- New Revision: B – Carbon Fiber
- Engineering Change Request: ECR-001
- Engineering Change Order: ECO-001

## Project Workflow

1. Created a Parts Register.
2. Developed an Engineering BOM (EBOM).
3. Created an Engineering Change Request (ECR).
4. Created an Engineering Change Order (ECO).
5. Simulated Engineering, Quality, Manufacturing, and Final Approval workflows.
6. Tracked Revision A and Revision B.
7. Compared the original and updated BOM.
8. Documented simulated validation checks and released Revision B in the project records.
